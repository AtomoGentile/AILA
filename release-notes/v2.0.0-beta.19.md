# AILA 2.0.0 — beta 19

- **Revisione tra pere:** rimossi gli indicatori di caricamento; spaziatura iniziale allineata alla Bacheca. Nel selettore Classe la voce è tornata a «Pere».
- **ACA:** campo di testo fermo durante il trascinamento, separato dal pulsante `+`; apertura dell’assistente più graduale.
- **Allegati ACA:** le opzioni sono subito disponibili, senza comparsa a cascata.
- **Light mode:** pannelli e selezioni bianche Glass meno opachi e meno staccati dallo sfondo.
