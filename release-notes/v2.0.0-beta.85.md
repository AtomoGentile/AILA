## Mappa posti

- In Gestione aula → Rotazione, il rappresentante può impostare il numero di mappe pubblicate per il ciclo delle file e l’attesa per le coppie.
- Alla fine del ciclo le file tornano disponibili. Il Priority Pass segue la propria rotazione nelle prime tre file.
- Le coppie tornano disponibili una alla volta. Con quattro mappe di attesa, la coppia della prima mappa può ritrovarsi alla sesta.

## Burocrazia e Brief

- Il rappresentante può aggiungere, modificare o rimuovere la scadenza di una pratica attiva.
- Il Brief mostra le pratiche da consegnare con una scadenza, in ordine di data. Una scadenza con lo stesso titolo e la stessa data di un evento compare una sola volta.
