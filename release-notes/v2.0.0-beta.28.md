# AILA 2.0.0 — beta 28

- **Crea evento con AILA Assistant:** dal calendario, la richiesta apre ora «Dettagli evento» con i campi compilati, senza passare alla chat generale.
- **Controllo prima del salvataggio:** titolo, materia, data, orario, categoria e note restano visibili nel modulo; l’evento viene salvato solo con «Aggiungi evento».
- **Generazione:** mostrati attesa ed eventuali errori nel foglio; tornando indietro, la compilazione in corso viene annullata.
