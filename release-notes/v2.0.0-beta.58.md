# AILA 2.0.0 — beta 58

- **Circolari e calendario:** il controllo dei duplicati richiede ora più di una parola significativa in comune; una materia condivisa non fa più sparire un evento diverso.
- **AILA Brief:** gli impegni di oggi con orario già trascorso non compaiono più tra quelli ancora da fare. Gli eventi senza orario restano visibili.
