# AILA 2.0.0 — beta 57

- **Bacheca:** puoi aggiungere fino a cinque allegati a una nuova proposta. I file sono visibili e apribili anche dai compagni.
- **Educazione tra pere:** puoi allegare file già dalla creazione di una nuova discussione, oltre che nelle risposte.
- Corretto un errore di compilazione nel flusso di creazione delle discussioni.
